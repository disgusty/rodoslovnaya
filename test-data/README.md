# test-data

Put `.ged` files here to run `npm run test:gedcom`. The folder is not committed:
it is meant for third-party samples and your own trees.

Public GEDCOM samples that were used during development:

- [gedcom.org — GEDCOM 5.5.5 samples](https://www.gedcom.org/samples.html) (UTF-8, UTF-16, remarriage, same-sex marriage)
- [findmypast/gedcom-samples](https://github.com/findmypast/gedcom-samples) (Kennedy, Queen, Habsburg — 34 000 people, …)
- [davidmoten/gedcom — sample from the 5.5.1 standard](https://github.com/davidmoten/gedcom/blob/master/src/test/resources/sample-from-5.5.1-standard.ged)
